# vibe.Ag — presentación del trabajo

Sistema A.G · práctica de interfaz · HTML + CSS

## Qué es vibe.Ag

vibe.Ag es el modo de trabajo: observar una interfaz real, **dividirla en bloques**, construir primero el esqueleto HTML y después vestirlo con CSS. No se clona el teléfono. Se clona la **página**.

## Método

```
Captura  →  árbol de bloques  →  HTML semántico  →  CSS por bloque
```

La forma circular de la foto vive en CSS: `border-radius: 50%` + `object-fit: cover`.

El humano decide el mapa; la máquina ayuda a materializarlo.
